# Online Vue + Docker Travel Assistant Implementation Plan

> **For Codex:** Follow this plan serially with `superpowers:executing-plans`. The user explicitly requested no automated test suite; use import/build/config checks instead.

**Goal:** Incrementally add a Vue 3 + FastAPI + Docker production runtime with OpenAI-compatible online Chat/Embedding APIs while preserving the existing Streamlit interface, travel planner, ChromaDB data, local model assets and optional LoRA training workflow.

**Architecture:** FastAPI exposes synchronous upload/status endpoints and a one-worker in-process guide task queue. Domain code keeps Pydantic schemas, Prompt generation, JSON repair, and citation validation. Vue polls task state through an Nginx `/api` reverse proxy. Chroma stores vectors generated by the online Embedding client and enforces model/dimension metadata compatibility.

**Tech Stack:** Python 3.11, FastAPI, Uvicorn, HTTPX, ChromaDB, Pydantic 2, Vue 3, Vite, TypeScript, Vue Router, Axios, Nginx, Docker Compose.
